# Tent King Group Corporate Website

A premium, responsive corporate website built with Next.js 15, React 19, TypeScript, Tailwind CSS and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

The project is ready for import into Vercel. No build-time environment variables are required.

## Before public launch

- Replace the representative Unsplash project imagery with approved Tent King Group photography.
- Connect the quote form to the preferred CRM, email service or server action.
- Add approved client testimonials and social profile URLs when supplied.
- Confirm the final canonical domain and privacy/terms destinations.

## Content sources

Core company messaging and service detail are based on the supplied Tent King Group profile. Public Tent King contact details were verified against the existing Tent King website. Mission, vision and values copy is editorially derived from the profile and should be approved before launch.


## SEO, Analytics & Launch Configuration

Set these Vercel environment variables before launch if available:

- `NEXT_PUBLIC_GA4_ID` — enables Google Analytics 4.
- `NEXT_PUBLIC_GOOGLE_SITE_VERIFICATION` — enables Google Search Console verification.

The site already generates `/sitemap.xml` and `/robots.txt` for `https://www.tentsking.co.za/`.
